# 会った帳

知人や友達と **いつ・誰と・どんな名目で** 会ったかを記録するアプリです。
「あの人と最後に会ったのはいつだっけ」「去年の飲み会は何回あったか」がすぐ分かります。

**→ https://kuru77.github.io/atta-cho/**

依存ライブラリなし・ビルド不要。オフラインでも開けます。iPhone では Safari で開いて「ホーム画面に追加」すると、アプリとして使えます。

## アクセスの制限（ユーザーID＋パスワード）

最初に開いたときにユーザーIDとパスワードを決めます。以後、開くたびに入力が必要です。

- **iPhone のパスワード保存（iCloud キーチェーン）に対応**しています。最初に設定したときに「パスワードを保存」を選ぶと、次からは自動入力（Face ID / Touch ID）で開けます。パソコンのブラウザやパスワード管理アプリでも同じように保存できます
- 記録はすべて **AES-256-GCM で暗号化** して、この端末のブラウザ（localStorage）にだけ保存します。鍵はユーザーIDとパスワードから PBKDF2-SHA256（31万回）で作り、メモリ上にしか持ちません。パスワード自体はどこにも保存しません
- 端末を他人に触られても、ブラウザの保存領域を直接のぞかれても、パスワードがなければ中身は読めません
- **自動ロック**：アプリを離れたらすぐ／1・5・15・60分操作しなかったら、から選べます（初期値は5分）。右上の鍵ボタンで今すぐロックもできます
- アプリ切り替え画面のサムネイルに中身が映らないよう、裏に回ると画面を隠します
- パスワードを5回まちがえると、30秒から始まって倍々に待ち時間が入ります（最大1時間）
- ユーザーIDとパスワードは設定画面から変更できます（変えたら iPhone に保存したものも更新してください）

> [!WARNING]
> パスワードを忘れると、記録を取り出す方法はありません（「パスワードを忘れた」から全消去してやり直すことはできます）。数字4桁より、6桁以上や英字まじりのほうが安全です。

## 記録するもの

| 項目 | 内容 |
|---|---|
| 日付・時刻 | 時刻は任意 |
| 会った人 | 複数人OK。名前を打つと候補が出て、いなければその場で新しく登録 |
| 種類 | 食事・飲み会・お茶・遊び・旅行・お祝い・冠婚葬祭・仕事・勉強会・オンライン・その他（設定で追加・名前変更できます） |
| 名目 | 「〇〇さんの誕生日祝い」「転職の報告」など自由に |
| 場所・メモ | 任意。場所は過去の入力から候補が出ます |

人ごとに、ふりがな・間柄・メモも残せます。

- **間柄**：友達・同僚などのほか、一度入力した間柄（「大学の同期」など）は保存され、次からは入力欄の下のボタンをタップするだけで入ります。もう一度タップすると外れます。一覧は設定 →「間柄」で追加・名前変更・削除できます
- **詳細な記録**（任意）：はじめは入力欄を出していません。設定 →「詳細な記録」をタップして、記録したい項目をオンにすると、人の登録・編集画面に入力欄が出ます

  | 項目 | |
  |---|---|
  | あだ名・呼び名 | 一覧で名前の横に表示 |
  | 性別 | 男性／女性／その他から選択 |
  | 誕生日 | 「1990/4/12」のように年まで入れると年齢も表示。「4月12日」だけでも可 |
  | 出身地・住まい（地域） | |
  | 学歴・経歴・職歴 | 複数行で書けます |
  | いまの勤務先・所属 | |
  | 家族・趣味・好きなもの | |
  | 知り合ったきっかけ・連絡先 | |

  項目をオフにしても、入力済みの内容は消えずに表示されます。詳細の内容も人の検索の対象になります。

## 見られるもの

- **記録**：月ごとの一覧、今月・今年の回数。名目・人・場所・メモで検索、種類で絞り込み
- **人**：最近会った順／**会っていない順**／回数順／名前順。半年以上会っていない人は色が変わります
- **人の詳細**：会った回数、今年の回数、最後に会った日、最初の記録、どんな名目で会ったかの内訳、一緒に会った人、その人との記録の一覧

## バックアップ

設定 → バックアップから。

- **書き出し**：暗号化したままの `.json`。読み込むには書き出した時点のパスワードが必要です
- **読み込み**：今の記録に合わせます（同じ記録は新しく編集したほうを残します）。別の端末へ移すときにも使えます
- **CSV**：表計算ソフト用。暗号化されないので扱いに注意してください

ブラウザのサイトデータを消すと記録も消えます。ときどき書き出してください。
